## 3. 预计工作量

- 初步预计6～8个修复主题批次；其中逐名复核仍按默认三人组展开，主题批次不是只检查18～24名。
- 武将及关联回归约30～50工程小时，包含归因、修改、必要测试与验收复核；这是工程工作量估算，不是精确完成时间。
- 根据本次报告时间跨度，完整回归加730场审计约4小时一轮；另预留两轮，约8小时机器运行时间，可能与整理工作重叠。
- 若用户后续要求同时修完战略系统等独立缺陷，暂另预留4～8工程小时；当前先归因、记录，范围按既有开发分工执行。
- 首批共同问题处理后，以实际根因数量、受影响范围和复测结果更新估算，不把重复报错算成重复修复任务。

## 4. 验收与状态口径

1. 武将相关的回归失败和错误清零；9项跳过均有原因与影响说明。
2. AI审计中的未处理动作执行、候选生成、决策与兜底异常清零；候选过滤和无有效影响记录有合理解释。
3. 关键技能/特性有确定性验证和代表轨迹；合法可用不等于有效机会，使用一次不等于符合设计。
4. 步数超限逐场得到结论；错误循环或明显策略空转必须修复，合法长局须记录依据。
5. 前端选取、预览、后端合法性、正式结算和公开日志一致。
6. 73名逐名复核结论、修复记录和经验文档同步；存在独立系统失败时，明确完整回归仍未通过，不能宣称全项目通过。
