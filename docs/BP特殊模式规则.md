# BP 每局武将池与特殊模式

本规则仅用于 BP 模式。**全体选择**每局进入禁选前，从已实现且可在普通房间选择的武将中抽出 **66 名不重复武将**，作为本局唯一可禁、可选的武将池。等级 1～10 按以 5.5 级为中心的钟形权重分配名额；某等级已实现武将不足时，剩余名额依权重补给其他等级。当前可玩武将的等级分布并不均衡，故以“受现有数量约束、尽量接近钟形”解释，不引入未实现武将。武将池、每级人数在 BP 界面公开；每局结束后重抽。**随机等级**沿用房主勾选等级中的全部已实现武将，不抽 66 人池。

全体选择随后从本局武将池实际包含的等级中随机禁用两个不同等级。系统只抽取禁用后仍足以完成双方全部手动禁选、且在等级上限内完成阵容的组合。队长只能从本局池中禁选，禁选记录与等级可完成性都只看本局池。随机等级逐轮从房主勾选的等级中抽取该轮等级，不执行系统禁级。

每局 BP 开始前独立随机一种《data/特殊规则.xlsx》的特殊模式，立刻向房间所有玩家显示名称和规则说明；开战后同一模式持续到该局结束。连局重新随机。抽到“无”即正常战斗。抽到 **Double Down** 时，再抽两个互不相同、且不为 Double Down 或“无”的模式同时生效，显示 Double Down 及两项规则；“大将模式”与“有种来单挑”叠加时先移除大将，再从剩余武将中抽单挑代表。其他同类限制取更严的条件。

源表没有明确的操作边界，按以下一致规则落地：

| 特殊模式 | 战斗处理 |
| --- | --- |
| 来把快速 | 所有在场单位当前速固定为 10；开场两队交叉行动表整体倒序。新召唤物同样速 10；与擂台赛叠加时，双方随机擂台顺序形成后整体倒序。与永恒轮回战场叠加时，速的累计加成仍记账，但本局有效速仍固定为 10。 |
| 同情弱者 | 以开场武将本体的攻、守、速、范分别找最高者；并列者都受对应限制。攻最高者不能使用直接造成伤害的主动技能；守最高者不受被动/反应技能影响；速最高者不能使用造成任何单位位移的技能；范最高者发动技能时有效范至多 1，和真回合制叠加也以 1 为准。限制不随中途数值变化转移；若与改变开场属性的规则叠加，则按叠加后的开场值比较。 |
| 慢速模式 | 每名真正武将本体在同一个武将回合内最多主动声明一次技能；主动、反应及瞬发均计入，自动触发的被动不算主动声明。普攻、普通移动与召唤物自己的技能不计入。 |
| 有种来单挑 | 各队从已选武将本体中随机一位上场，其他武将不入场；这两位按原本规则对决，任一方代表被击破即该方失败。 |
| 真男人模式 | 所有在场单位获得魔免；普攻和普通移动仍可进行，技能只允许主动技能，不能使用被动、反应、瞬发技能。普攻不是技能，不受“只能使用主动技能”的限制。 |
| 大将模式 | 两队各自初始等级最高的武将不入场；并列最高时随机决定其中一位。其他武将正常战斗。 |
| 不会打伤害的辅助不是好刺客 | 每次实际回复生命，随机一名相对施放回复者的敌方存活武将失去同量生命；每次实际回复当前魔，随机一名相对施放回复者的敌方存活武将失去同量魔。没有施放者的自然回复按受益者所在队计算。追加损失不开放连锁，不再递归触发本规则；无敌方存活武将时不产生额外效果。 |
| 老一套对我没用 | 所有单位不能回复生命或当前魔；初始化魔量与技能费用不算回复。 |
| 骤死模式 | 一方任意真正武将本体首次被破坏时立即判该方失败；分身、召唤物和军兵不计。 |
| 软柿子 | 真正武将本体遭破坏时，只从**己方**开场行动顺序向后寻找下一位仍存活的武将本体（末位可循环到己方首位），由其代替被破坏；原武将从初始完整状态在原地重生。原武将自身的召唤物与持续效果清除；原武将不触发自己的死亡后技能。攻击者先结算击破奖励，再重置原武将并执行替死。己方没有另一位存活武将时，原武将照常被破坏；因此单挑模式中的代表不会由对手替死。 |
| 我们都是法师 | 每个武将自己的回合末，先处理其他回合末效果，再把当前魔补至上限；处于隐身状态者不补魔。与禁止回复叠加时不能补魔，补魔反噬照常触发。 |
| 擂台赛 | 双方各按开场随机顺序逐位派武将；每方只有当前擂主可行动、被影响与受伤，其他武将及其召唤物候场且不受生命、魔、状态、移动等效果影响，也暂不进入回合；擂主被破坏后派下一位。某方无人可派时落败。 |
| 不是，这怎么有根铁链? | 记录开场同队相邻武将行动位之间的最大距离。任一武将本体移动结束后，下一位同队武将若超出原距离，则强制移动到能恢复距离的最近合法格；该跟随不耗移动点数，并依行动顺序继续带动后续队友，但不会绕回推动最初移动者。 |
| 永恒轮回战场 | 棋盘中央固定 5×5 区域并在战场格子上标出；每个完整全局轮次结束时，若区域内仅有一队的存活武将本体，则该队所有存活单位随机一项攻、守、速、范永久 +1，可叠加。 |
| 真回合制 | 所有单位的范覆盖整张棋盘；其他技能的目标形状、直线和遮挡要求仍按技能自身文字处理。 |
| 刚正面！ | 只能对敌方当前守最高的存活武将本体造成伤害；并列最高者都可受伤。其他对象的伤害被阻止，非伤害效果照常。 |
| 无 | 本局无额外规则。 |

特殊模式属于整场战斗规则，不能被普通魔免、天气替换或来源武将死亡移除。持续状态与本局战斗存档、重连和回放一起保存。

实现边界：直接写入武将当前生命或当前魔量的技能也受“禁止回复”和“回复反噬”约束；伤害结算之外造成的武将本体阵亡也会在统一阵亡清理时触发“骤死”“软柿子”和“擂台赛”。“软柿子”的替死者不会再触发一次替死，避免重复重置。擂台候场武将不会获得“永恒轮回战场”的区域加成。单挑代表一旦被击破就立即判胜，即使其武将技能原本允许之后回场。整场模式的技能限制对普通效果免疫武将同样生效。
