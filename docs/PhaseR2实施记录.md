# 救援 Phase R2 实施记录

> 状态：已结束（负责人确认）  
> 进入日期：2026-08-16  
> 工程完成日期：2026-08-23  
> 负责人确认日期：2026-08-23

## 1. 当前问题

战役已经具备地图、城市选择、职位工作台和卷宗，但进入战役后的视觉顺序仍像纵向网页：快速战役先显示整块国策/建议，再显示地图和月报；长期战役还会先显示危机、圣物、引导和月报。地图因此存在却不是主操作画面，右侧职位工作台又是一条过长的独立滚动栏。

现有建局表单和战役列表在选中战役后已经隐藏，卷宗也已折叠；R2 不重做这些已经成立的基础，而是重新组织战役内部的主次关系。

## 2. R2 分段

- R2.1：地图优先战役外壳。地图固定为主舞台，国策/本月聚焦/月报等进入旁侧行动栏，并补返回战役列表入口。
- R2.2：地图视觉层级与稳定选择。梳理归属、路线、军队、围城、危机、警报与已计划军令。
- R2.3：城市上下文军令栏。让所选城市摘要、风险、计划和当前职位合法操作相邻。
- R2.4：卷宗与管理后台降级。保持成员、恢复、协作、队列、目标、战斗、英灵、科技和事件可达但不干扰主流程。
- R2.5：桌面/手机完整走查与复盘。

## 3. R2.1 验收点

- 进入战役后地图先于国策、建议、危机、圣物、引导和月报成为主舞台。
- 桌面可同时看到地图与当前行动栏，地图占据更大的视觉面积。
- 手机仍可通过地图/军令/卷宗固定入口一跳到达，点击城市后直接落到行动栏。
- 快速战役国策、三项聚焦、长期战役情报、现有职位工作台和月报不丢失，不修改任何后端规则或数值。
- 玩家可返回战役列表切换存档，不需要刷新或退出账号。

## 4. R2.1 完成结果

- 战役主结构改为“地图主舞台 + 当前行动/城市军令侧栏”；地图先于快速国策、三项聚焦、危机、圣物、引导和月报渲染。
- 桌面 1280×720 中，地图约 695px、行动栏 420px，同屏可见且没有页面级横向溢出。
- 手机 375×812 中，地图/军令/卷宗固定入口保持可用；地图选城后直接把“城市名 · 当前职位”标题定位到固定导航下方，没有被国策或月报截住。
- “战役列表”可从活动战役返回账号存档列表；快速战役开局前后都保持地图优先，国策后三项行动仍完整显示。
- 浏览器控制台无报错；前端专项 25 项、行为层 187 项、完整回归 757 项通过，8 项按环境跳过。

## 5. R2.2 验收点

- 城市归属显示“己方 / 敌方 / 中立城邦 / 无主”的文字和符号，不只依赖边框颜色。
- 当前目标、叛乱/危机警报、已计划军令、军队、遭遇和围城在城市节点上有不同层级的短标签；完整情报仍保留在路线抽屉和行动栏。
- 普通、补给、行军和严寒路线具有可区分的线型与图例，不把所有路线显示成同等重要。
- 当前目标使用 `aria-pressed` 和可见“当前目标”标记；地图与城市军令标题保持同一选择。
- 选择按战役和职位记忆：轮询重绘不改变目标，受限职位首次切换到合法管理城市，切回原职位恢复原目标。

## 6. R2.2 完成结果

- 城市节点新增“◆ 己方 / ⚔ 敌方 / ◇ 中立城邦 / ○ 无主”标签，归属不再只靠边框颜色；势力名、兵力与城防保留为第二层信息。
- “◎ 当前目标 / ⚠ 警报 / ✓ 已计划 / ▸ 军队 / ⚔ 遭遇 / ▣ 围城 / ❄ 雪鬼威胁”使用各自的文字、符号和视觉层级；节点只显示最多两支军队，完整路线、补给、军队、遭遇和围城情报继续保留在路线抽屉。
- 普通路线降为细虚线，补给、行军和严寒路线使用不同颜色、粗细与线型；图例同步显示当前战役实际存在的路线/战况类型。
- 当前目标同时使用可见“◎ 当前目标”、放大描边和 `aria-pressed`；地图、开局结果、局势简报、AI 目标、引导、危机与关键决策的定位入口统一更新同一选择。
- 选择按“战役 ID + 当前职位”分别记忆。普通轮询/手动刷新不重置目标；城主/将军首次进入时回到合法管辖城市，切回主公或其他职位时恢复该职位此前目标。
- 手机仅让 720px 地图画布内部横向拖动；标题、说明、图例和路线抽屉保持手机正文宽度。375×812 页面无横向溢出，地图点城后所选城市军令标题停在固定导航下方。
- 1280×720 桌面保持约 693px 地图与 420px 行动栏并列，5/5 城市节点完整落在画布内；真实浏览器刷新后仍保持所选城市，页面错误记录为空。
- 前端专项 26 项、行为层 188 项、完整回归 758 项通过，8 项按环境跳过；前端脚本语法检查通过。
- 本单元只改变前端信息层级、可访问状态和选择记忆，不修改玩法数值、AI、官职权限、后端合法性或结算顺序。

## 7. 数据边界

自动化和浏览器走查只能验证布局、操作可达性与功能无回归。真人对地图理解速度、继续游玩意愿和 25～35 分钟完成时长仍需要真实样本，当前不得标记为通过。

## 8. R2.3 验收点

- 地图旁侧栏和手机地图后的操作面都先显示所选城市，不再先穿过整块国策、建议、危机或月报。
- 城市首屏同时显示归属、方针、核心资源、兵力/城防、风险和本月已排计划；没有风险或计划时也有明确空状态。
- 当前职位针对这座城市可执行的现有动作紧接城市上下文；职位级案牍、军团、国家科技、圣物、英灵等工作继续保留在其后。
- “本月局势与建议”移到城市/职位操作之后，快速国策、三项聚焦、长期危机、圣物说明、引导和月报不丢失。
- 地图选择、军令标题、城市摘要和实际提交载荷保持同一城市；受限职位仍只能看到并执行原权限允许的动作。
- 桌面保持地图与城市军令并列，手机点击城市后直接落在紧凑城市上下文顶部，无页面级横向溢出。

## 9. R2.3 完成结果

- 地图旁侧行动栏固定为“军令标题 → 所选城市上下文与城市军令 → 当前职位工作 → 本月局势与建议”；快速国策、三项聚焦、长期危机、圣物、引导和月报全部保留，但不再挡在城市操作前。
- 城市卡首段统一显示归属、当前职位、方针、粮/钱/人口/以太/兵力/城防、兵种、当前风险和本月计划；无风险与无计划分别显示“当前无警报”和“尚未为本城安排军令”。
- 主公、大将军、将军和城主四种工作台都先显示城市卡，再显示职位案牍、军团、科技、祭祀、圣物和英灵等职位级工作；旧的主公/大将军普通城市卡隐藏规则已移除。
- 当前职位对本城可执行的既有动作紧接计划摘要。敌城继续显示原权限限制和己方城市出口提示；地图目标、军令标题、城市摘要和原提交载荷保持同步，没有新增动作或放宽权限。
- 1280×720 桌面保持地图与 420px 城市军令栏并列；375×812 手机点城后军令标题位于屏幕上方，城市六项数据、风险、计划和“当前职位可执行”落在首屏内，页面无横向溢出。
- 真实浏览器切换己方/敌方城市、刷新与手机定位均通过，页面警告/错误记录为空；前端脚本语法检查通过。
- 前端专项 27 项、行为层 189 项、完整回归 759 项通过，8 项按环境跳过。
- 本单元只改变前端信息架构、文案和视觉层级；玩法数值、AI、官职权限、后端合法性、结算顺序和现有决策数量均未改变。

## 10. R2.4 验收点

- 战役主流程外只保留紧凑战役状态；成员、邀请、月度提交、恢复、官职协作、行动队列、战略目标、战斗、英灵、科技和事件全部进入默认折叠的“战报卷宗”。
- 卷宗展开后按成员、军令、目标、战斗、英灵、科技和事件等实际可用分类分页；恢复与官职协作明确归入成员页，不落入含糊的“其他”页。
- 任意时刻只显示一个卷宗页；切换分页不重绘地图和城市军令，不清空未提交的界面选择，也不改变后台规则或权限。
- 分页具备可读的 tab / tabpanel 语义、选中状态和左右方向键切换；手机端分页只在卷宗内部横向滚动，不造成页面级横向溢出。
- 没有战役事件时显示明确空状态；现有管理按钮、恢复入口、战斗入口、科技和英灵操作保持可达。

## 11. R2.4 完成结果

- “战报卷宗”默认收为 49px 紧凑入口，并显示可用资料类别数量；战役状态条仍留在主流程，所有直接管理标题均不再散落在地图之后。
- 成员页集中成员/邀请、异步提交与在线状态、战斗恢复和同势力官职协作；行动队列、目标、战斗、英灵、科技和事件各自按实际内容生成独立分页。
- 分页切换改为原位显隐，不再调用整座战情室重绘；活动分页具有 `aria-selected`，其余分页隐藏，鼠标、触屏和 Home / End / 左右方向键均可切换。
- 1280×720 桌面中地图约 693px、军令栏 420px，卷宗保持折叠且页面无横向溢出；375×812 手机从固定“卷宗”入口可直接看到紧凑卷宗，展开后的分页在 250px 内部区域横向滚动，页面本身不横移。
- 真实浏览器中卷宗始终只显示一个活动页，手机切到末页与键盘回切均通过，页面警告/错误记录为空；前端脚本语法检查通过。
- 前端专项 28 项、行为层 190 项、完整回归 760 项通过，8 项按环境跳过。
- 本单元只改变前端收纳、分页、焦点和空状态；玩法数值、AI、官职权限、后端合法性、结算顺序和现有决策数量均未改变。

## 12. R2.5 走查范围

- 使用同一账号和真实本地服务，分别在 1280×720 桌面与 375×812 手机视口覆盖快速战役第一月、选择国策后的普通月份、六月评议、长期战役和归档只读五种状态。
- 核对地图/城市军令的视觉顺序、城市选择与操作到达、固定入口与触屏目标、卷宗焦点、页面横向溢出和轮询重绘稳定性。
- 核对快速战役国策、普通月最多三项聚焦、六月评议；以及长期战役危机、圣物、前三月引导和月报均没有因 R2 重排丢失。
- 核对归档后完整复盘可读，推进、军令和其他玩法操作不可执行。

## 13. R2.5 完成结果

- 快速首月在桌面保持约 693px 地图与 420px 军令栏并列；手机固定“地图 / 军令 / 卷宗”入口均为 45px。点选敌城后，军令入口直接到达相同城市标题，城市选择、卷宗展开、事件分页和焦点在 5.2 秒轮询后全部保持。
- 选择“立即整军备战”后效果即时写入，第二月保留开局反馈并只突出治理、外交、军事三项行动；地图仍是主舞台，桌面与手机均无页面级横向溢出。
- 六月结算让位于评议主界面，排名、分项、完整复盘和继续/归档/重开按钮保持可用。结算状态的固定入口由误导性的“地图”改为“评议”，页头同步说明当前决定；三个手机终局按钮均为 45px。
- 长期战役的 8 城地图、严寒路线、雪鬼危机、圣物与祭坛、前三月引导和月报均保留在地图旁侧行动栏；手机地图画布为 256px 可视宽、736px 内部滚动宽，页面本身不横移，点选中立城市后可直达对应军令标题。
- 归档状态改用只读页头说明，推进与军令禁用且没有可执行玩法按钮；评议与完整复盘保留。走查修复了复盘展开卡片“浅色底 + 浅色字”造成的不可读问题，桌面和手机均恢复清晰对比度。
- 五类状态在两种视口下页面横向溢出均为 0；浏览器警告/错误记录为空，前端脚本语法检查通过。
- 代表性自动化覆盖快速首局、十二月长期结算、账号恢复与归档只读、战略面板完整内容及 R2 壳层；前端专项 28 项、行为层 190 项、完整回归 760 项通过，8 项按环境跳过。
- 本单元只修正信息架构、状态文案和复盘对比度；玩法数值、AI、官职权限、后端合法性、结算顺序和现有决策数量均未改变。

## 14. R2 阶段复盘

R2.1～R2.5 已达到工程退出门槛：活动战役以地图为主舞台，桌面不经长页面滚动即可同时看到地图与军令入口；手机可以一跳到地图、所选城市军令和卷宗，点城与操作目标一致且没有页面级横向溢出。地图归属、路线、警报、选择和计划不只依赖颜色；后台轮询不再打断当前选择或卷宗浏览。快速与长期战役原有功能、后端规则和结算顺序均未改变。

负责人于 2026-08-23 明确要求进入 R3，视为确认本复盘并结束 R2。R3“决策与反馈压缩”已经开始。
