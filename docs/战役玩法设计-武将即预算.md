# 战役玩法设计：武将即预算

本文提出把战役的核心循环从「势力每月 4 点军令」改为「每名在职武将每月一条指令」，并把可执行的动作挂到武将技能上。这是设计稿，尚未实现，供评审后再动代码。

---

## 一、现状诊断

动手之前先说清三件事，它们各自都会让原计划落空。

### 1. 现在的军令预算管不住主要动作

`enforce_faction_command_points` 全项目只有一处调用：`strategic/api.py:776`，也就是 `queue-action` 端点。

而城市方针、解锁战术科技、宣战这三件事，前端走的是各自独立的即时端点（`static/strategic/api.js` 第 528、545、595 行 → `api.py` 的 `post_strategy_campaigns_set_city_policy` / `unlock_tactic_tech` / `declare_attack`）。那条路只调 `require_strategy_action_office` 查官职权限，**不查也不扣军令**。

实际后果：一个月内可以给全部 8 座城改方针、解锁所有买得起的科技、从每座城宣战，头上的计数器自始至终显示 4/4。

这也解释了"4 点预算对着 40 种动作"的怪象——预算不是设计得紧，是它只管到了次要动作。**任何新预算若不先合并这条通道，都会同样管不住大头。**

### 2. 武将的战略专长是从战术属性算出来的，不是逐个写的

`strategic/hero_personal.py:66` 的 `hero_specialty_for_code` 按 attack / defense / speed / mana 谁最高，把武将分进四个桶：

| 判据 | 专长 | 月度效果 |
|---|---|---|
| mana 最高且 ≥3 | 以太学者 | 辅佐内政时所在城 以太 +10 |
| defense 最高 | 坚守卫士 | 驻守时该城 兵力 +25、支持 +1 |
| speed > attack | 军务教习 | 训练时该城 兵力 +35 |
| 其余 | 先锋统御 | 随军时士气 +3，无军队时后备兵 +15 |

这与"三国志靠属性区分角色，而我们的武将各不相同"的方向正好相反：战略层把本来各具技能的武将，重新压回了四个属性桶，每桶一个数值加成。

### 3. 官职是权限轴，且大多不由武将担任

`strategic/offices.py:30` 的 `OFFICE_PERMISSIONS` 按 lord / grand_general / general / governor 四类授予权限，`require_strategy_action_office` 据此放行。但官职是**按城自动生成**的（每座己方城市一个 governor），开局 8 城就有 8 个 governor + 1 lord + 若干 grand_general/general，其中绝大多数 `controller_type = "ai"`，`holder_id = None`。

武将是被**任命**进官职的，不是官职本身。所以"在职武将数"远小于"官职数"，两者不能混为一谈。

## 二、核心改动：预算单位从「点」改成「人」

### 规则

**每名在职且清醒的己方武将，每月提供一条指令。**

- 预算 = `status == "serving"` 且非 `sleeping` 的己方武将数
- 每条排队指令记名到一名武将（新增 `executor_hero_code` 字段）
- 一名武将一个月只能执行一条指令

### 为什么这是对的

**它把抽象数字换成了屏幕上看得见的东西。** "军令 3/4 可用"是一行需要解读的文字；"四个人里有一个还闲着"是一眼可见的状态。武将列上的闲置高亮从示意变成真规则。

**它让既有的数值有了战略后果。** 战败沉睡 2 月（`STRATEGIC_HERO_BATTLE_SLEEP_MONTHS`）现在只是"这个人暂时不能出战"；改制后它等于**未来两个月各少一条指令**。忠诚流失导致出走同理。这些系统已经写好了，只是此前不影响你的行动力。

**它给了招募一个第一动机。** 现在招人是为了多一个能出战的单位；改制后是为了多一份行动力，这是战略游戏里更根本的驱动。

**它天然适配多人。** 每条指令记名到武将，而武将有 `controller_user_id`，多人战役里的"谁花了预算"自动分账，不需要额外规则。

### 预算中性

开局 4 名武将对应现在的 4 点，两者几乎相等。**这不是一次平衡地震，而是把同一份预算的来源从"势力凭空拥有"改成"由你有谁决定"。** 前期手感不变，中后期随人员增减而浮动。

### 取消多点成本，改用技能门槛

现在 `declare_attack` 花 2 点、`peaceful_integration` 花 2 点。在按人计的预算里"花 2 点"很别扭——是哪两个人？

建议：**预算单位统一为"一人一条"，动作难度不再用点数表示，改用技能门槛。** 和平整合之所以难，不是因为它花两条指令，而是因为需要一名「辞令」达到进阶的武将。这样预算永远好懂（几个人几条令），难度则随技能成长而可扩展。

## 三、技能体系

### 从四个属性桶换成一张可增减的技能表

用 `HERO_SKILLS` 取代 `HERO_SPECIALTIES`。区别在三点：

1. **逐个武将撰写**，不由属性推导。同为高防御的两名武将可以一个会「安民」一个会「营造」。
2. **一名武将可持有多个技能**，开局 1–2 个。
3. **技能可增可减**，这是与三国志最大的区别，也是本项目的立身之处。

### 技能决定"会不会"，官职决定"准不准"

两者不是重复，而是相乘——**一个动作要求技能 ∧ 官职**。

- 官职（authority）：你有没有资格对这座城下令。已由 `OFFICE_PERMISSIONS` 实现，不动。
- 技能（capability）：你会不会做这件事。新增。

这正是三国志的"官职 + 适性"，但适性在那里是静态数值，在这里是会变的技能。于是"武将获得或失去技能"真正改变**你能下什么命令**，而不只是改变一个加成数字。

### 第一批技能（8 个）

| 技能 | 覆盖动作 |
|---|---|
| 统军 | 宣战、编军、行军 |
| 练兵 | 征守军、注册兵种 |
| 治政 | 城市方针、解锁科技 |
| 营造 | 筑城 |
| 安民 | 平叛处置 |
| 辞令 | 中立外交、和平整合（进阶） |
| 谋略 | 教唆中立、搜索圣物 |
| 以太 | 祭祀绑定英灵、以太类科技 |

### 获得与失去的时机

获得：
- 个人任务完成（`personal_mission_status` 已有完整状态机，`hero_personal.py`）
- 战斗表现（`record_hero_battle_outcome` 已在战后被调用，目前只改忠诚）
- 主公授学（新动作，由持有该技能的武将传授）
- 故事事件后果（`story.py` 的 consequence 已支持延迟生效）

失去：
- 忠诚跌破阈值（`loyalty_band` 已有 5 档）
- 战败沉睡醒来后（有几率）
- 故事事件后果

四个获得来源里有三个的宿主系统已经存在，只是当前只写忠诚和关系，不写技能。

## 五、收费规则：改变才收

按评审决定，三条免费通道并入统一预算，但**常驻设置与本月行动区别对待**：

- **城市方针**：常驻状态而非月度动作。维持现状不花指令，**改动才花**。代码上 `tactics.py:437` 已经在新旧方针相同时提前返回，天然契合这条规则。
- **解锁科技**：一次性动作，每次花一条。
- **宣战**：每次花一条（由取消多点成本，从 2 点变为 1 名武将）。

实现上把 `enforce_faction_command_points` 从 `queue-action` 单点调用，提升为三个即时端点共用的前置检查。

## 六、迁移与兼容

- `FACTION_MONTHLY_COMMAND_POINTS` 保留为回退值：没有武将系统的旧存档（或武将数为 0 的边界）仍按 4 点计算，不至于变成 0 条指令而卡死。
- `QueuedAction` 增加 `executor_hero_code`；旧存档的排队行动该字段为空，按旧规则结算。
- AI 势力的预算同样按武将数计（`ai.py` 的 `apply_strategy_ai_monthly_actions` 已经读 `faction_command_points`，改一处即可），保证人机同规则。

## 七、实施分期

| 阶段 | 内容 | 可验证的结果 |
|---|---|---|
| P1 | 堵免费通道；预算改为按武将计；指令记名到武将 | 武将列的闲置高亮成为真规则；改方针会扣指令 |
| P2 | `HERO_SKILLS` 技能表；动作按 技能 ∧ 官职 双重门槛 | 点一名武将，右侧只列出他真能做的事 |
| P3 | 技能的获得与失去接入既有的任务/战斗/故事/忠诚系统 | 一局之内武将能力会变化 |
| P4 | 界面收编：第一批 14 个动作之外的暂时隐藏 | 屏幕上的选择数量降到可决策的量级 |

P1 是唯一会改变现有平衡的一步，且幅度极小（开局预算不变）。P2 起都是加法。

## 八、尚未决定的问题

1. **故事事件与危机分支是否占预算。** 它们是有时限的被动响应，超时自动放任。占预算会让"被事件淹没"变成真实压力，也可能让玩家在关键月份无事可做。
2. **无技能武将能做什么。** 建议保底允许所有人执行"驻守"和"随军"这类不需要专长的指令，否则新招募的白板武将等于没有行动力。
3. **技能等级还是有无。** 上表的"辞令（进阶）"暗示了等级制。等级更能表达成长，但也多一层数值需要平衡；先做有无、把和平整合的门槛改为"辞令 + 某项前置"也可行。
